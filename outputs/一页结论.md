# 年报语义地图 RAG｜验收结论

## 交付结果

已将项目目录中现有的 2026 年半年报语料构建为可互动页面。索引覆盖 **9 家公司、3,576 个文本块**；本地 `Qwen3-Embedding-0.6B` 在 RTX 3060 Laptop GPU 上生成 **1,024 维**向量，并与 BM25 混合检索。页面支持按公司筛选、二维语义地图点选查看原文、输入问题、查看引用证据及回答。

回答后端使用 **GPT-6 Luna（`gpt-6-luna`）**。10 道实际问答请求均返回 HTTP 200；按预期事实逐题核对为 **10/10 答对**，平均响应约 **4.58 秒**。其中 3 道跨公司题分别对比 3 家、2 家、2 家公司；生成答案中的主要数字均有年报块 ID 和页码可回查。逐题问题、答案、预期值、召回块、引用块和判定见 `evaluation_results.csv` 与 `evaluation_results.json`。

## 观察与限制

跨公司检索按问题中点名的公司分配证据块，避免用未提及公司的同类指标污染答案。表格已保留为带行列标记的文本，但少量 PDF 提取文本会把标签拆开或把数值放在相邻行；检索按现有块结构处理，现金流对比已优先匹配半年报主要财务指标表。本次 10 题是针对现有语料的定向验收，不代表所有问题类型均已覆盖；自动回答仍建议对照所引原文复核。

## 启动

在 Windows PowerShell 运行 `outputs\run.ps1`，然后访问 `http://127.0.0.1:8765`。本机需保留 `D:\AI任务\知识库` 下的原始 JSONL 与 Qwen 模型；启动时使用 `work\.secrets\openai_api_key.txt` 中的密钥，只在本机后端调用 API。
